Who is annotating?

Enter your name (no password). It is used as your annotator id; labels are attributed to it.

Your labels are stored on this device and synced when online. Independent annotation still applies to new labels. To fix a mistake on any image (yours or someone else's), use Go to with the image id; edits are saved as corrections and become the current label.

Attributes v1.1 shows images that already have their v1.0 labels (shown as context) and asks for the new attributes only; it never changes v1.0 labels or their done status. Weather is what you can see: indoor_na indoors, night for outdoor night shots. size_class is a visual impression (standard / wide / pediatric_size), not a measurement. Chair subtype appears right below device type once the chair is manual or powered (yours, the v1.0 label, or — marked "AI" — the model's guess); it is optional here, so number keys skip it — tap it or use ↑/↓; drive wheels for powered chairs. Securement hardware (docking bracket / tiedown points / not visible / unclear): label only what is visible — e.g. an EZ Lock / Q'Straint docking pin under the seat, or WC19-style tiedown loops; never guess from brand alone; prefer unclear. This is not a safety certification. Ramp deployment is a research judgement of the scene (safe / unsafe / not needed / unknown), not a safety assessment; ramp reasons is multi-select (number keys toggle; unknown alone).

Images are shown face-blurred (as they will be released) wherever scripts/auto_blur.py has processed them. If you can still recognise a face, press f; those images get re-blurred by hand before release.

Dashed blue = weak-label suggestion from proposed_class (normal mode); it is only saved when you press Done or click it. Orange = machine suggestion with its confidence (review mode). Confirmed or fixed values are saved under your name, with a note that they were model-suggested; the model itself never counts as an annotator and never excludes an image. Queue order (review): lowest model confidence first (default), untyped wheelchairs first, or random; images that already have one human label are offered first so every image gets two independent people.
