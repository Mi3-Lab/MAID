## Label / suggestion agreement (zero-shot bias)

Labelers reviewed SigLIP2 zero-shot suggestions (`annotations/auto/siglip2-so400m-224_zs-v1.jsonl`) while labeling, so the zero-shot row is evaluated against labels it influenced. Every SigLIP-based row shares that backbone, so it is biased upward too, but less.

| subset | n | final label = suggestion | deciding label event accepted the suggestion unchanged (auto_review) |

## Caveats

- Small test set (n = 65; lookalike 2, other_aid 8): CIs are wide and per-class F1 for rare classes swings with single images.
- Zero-shot SigLIP2 is biased upward (labels were confirmed from its suggestions); SigLIP-based trained rows inherit some of that.
- Most labels are single-annotator (319 of 433; 99 consensus, 15 adjudicated).
- Seed spread reflects training randomness on one fixed grouped split, not split-to-split variance. One uploader group (flickr:44636446@n04, 188 images) sits entirely in one split.
- YOLO11-cls uses Ultralytics' own recipe (augmentation, optimizer, no class weights), so it is not identical to the ResNet/SigLIP recipe.
